# Setting - Magic

## Provides
One result on the Magic table: what it is, what it does, and how long it lasts. What holds
a find is the location's; an item with a name and a history of its own is
`patterns/setting/UniqueTreasures.md`'s.

## Spec

```
MAGIC RESULT
  1     What it is - named as the thing itself, with no word on where it is found
  1     Does - stated plainly enough to adjudicate, at the strength GENRE.md's Magic
        level gives an ordinary find
  1     Lasts                                                               {LASTS}
  1     Tell - what shows it is magic before anyone uses it
  1     Value and Wt, in the coins and wt of setting/Treasure1.md
```

```
LASTS - exactly one
  once         - spent on its first use
  charges      - a stated number of uses
  lasting      - works until lost or broken
```

## Constraints

- **Never decide the container.** A result is reusable everywhere and tied to no place.

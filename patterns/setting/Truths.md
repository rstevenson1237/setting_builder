# Setting - Truths

## Provides
The rules this setting keeps that a generic instance of the genre does not.

## Spec

```
TRUTHS
  3-6   Truths
  1     Each stated in ONE sentence - the rule, not the feeling of the rule
  1     Each carries a Handle: what a party does about it, and the Location Code(s)
  1     Each is a rule, class, or idea - never a single object
  1     At least one a party discovers by acting, not by being told
  1     At least one that costs somebody something
  1     None restating what History or Setting already established
```

**The Handle is the whole test, and it is why this file is not a mood board.** Write it as an
action a referee could adjudicate: *deface an old-tongue stone and whatever it was holding is
no longer held* is a handle; *the old letters carry a weight nobody can explain* is the same
idea with nothing to grip.

Handles are completed at 5c, and **every truth is re-tested then.** A truth no location
cashed out is cut - it was atmosphere that survived because nothing had yet been built to
contradict it. This is the one place the framework deletes rather than revises.

**Discoverable by acting.** A truth nobody can find out is a note to the referee.

## Constraints

- **A Truth is a class, not an instance.** "The Ninefold Ledger is a cursed book" is an
  object and belongs in `setting/UniqueTreasures.md`. "Written oaths bind here, and breaking
  one marks the breaker visibly" is a truth: a class of object, a rule the world keeps, and a
  hundred later details following from it.

- **A truth that only ever appears once was a location feature wearing a costume.** What a
  settlement builds, what wild country does, and what a ruin's builders guarded against
  should all be able to show the same one.

- **A Truth must sharpen the genre, never override it.** A Truth that makes magic common or
  authority central has broken the setting rather than distinguished it.

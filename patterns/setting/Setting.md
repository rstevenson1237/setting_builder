# Setting - Setting

## Provides
The setting's name and the referee-facing outline every other artifact builds on. The
thematic tags are `patterns/setting/Tags.md`'s; this file only points to them.

## Spec

```
SETTING
  1     A name, per GENRE.md's Naming answer
  1     A single tag-line pointing to setting/Tags.md
  1     What the party is doing here, in a clause
  1     A pressure - something already going wrong, which is not aimed at the party
  1     Something the setting has that a generic setting of its genre does not
```

## Constraints

- **Never embed tags.** The tag-line points; the pool lives in `setting/Tags.md`.

# Setting - Setting

## Provides
The setting's name and the referee-facing outline every other artifact builds on. Tags
are decided separately, by `patterns/setting/Tags.md` at step 1b - this file only points
to them.

## Spec

```
SETTING
  1     A name, coined from setting/Language.md, and the roots recorded back
  1     A single tag-line pointing to setting/Tags.md - do not embed tags here
  1     What the party is doing here, in a clause
  1     A pressure - something already going wrong, which is not aimed at the party
  1     Something the setting has that a generic instance of the genre does not
```

**Outline discipline.** Two or three sentences for the referee, not for players: what this
place is, how it is run, and what it is for within the module. A sentence that does not help
a referee decide something at the table is description and belongs elsewhere.

**What makes it not generic** is one thing true here and nowhere else, stated in a clause,
and it should change how a party *acts* rather than how the place looks.
`setting/Truths.md` develops it; the outline names it.

## Constraints

- **A standing obligation is one option, never the default.** A debt, a tithe, a blood-price
  or a service owed is one thing a setting can be built on, and an economic instrument is a
  flavor of that one thing - never the setting's engine. The genre's answer to "how does
  this run with no overarching authority" is more often a fortified point of civilization, a
  dungeon's reputation, or a route something has cut.

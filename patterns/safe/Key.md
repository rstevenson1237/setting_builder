# Safe - Key

## Provides
How a settlement comes to be holding an object that opens something somewhere else. What
earns a Keys row is `patterns/setting/Keys.md`'s.

## Spec

```
KEY
  1     The object, and what it physically is
  1     What it opens, named by location code and feature
  1     Who has it here, and whether they know what it is - the holder is the obstacle
                        {collateral | heirloom | unexamined property | a cheap ordinary thing}
  1     What it takes to get it  {bought | borrowed | traded | stolen | inherited | earned}
  30%   A clue connecting object to lock
  20%   Somebody else wants it, and is closer to getting it - how close, so delay has a
        price
```

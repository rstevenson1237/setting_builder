# Wild - Key

## Provides
An object out in the open whose real function is opening something elsewhere; the lock
belongs to whichever location holds it. What earns a Keys row is
`patterns/setting/Keys.md`'s.

## Spec

```
KEY
  1     Object - what it physically is
  1     Opens - the location it opens, by code
  1     Feature - the feature there it opens
  1     How here - how it came to be out here rather than with its lock
                        {carried and never arrived | hidden on purpose | a grave good |
                         built into something as though a component}
  1     Where - where it sits now
  1     Keys row - a stub row in setting/Keys.md naming this location and the one it
        opens
  30%   Clue - connecting object to lock, shared in the making and never stated
                                          {a mark | a material | a tongue | a measure}
  20%   Known - somebody else knows it is here
```

# Dangerous - High

## Decides
What a high-weight location guarantees.

## Read at
Step 4c, for a location its gazetteer stub marks high. Generate the region's high-weight
locations first, so medium and low can foreshadow what has already been decided. Read with
`dangerous/Dressing.md`, `dangerous/Secrets.md`, and the element files the features draw
from.

## Spec

```
DANGEROUS - HIGH
  1     Challenge            {creature | trap | mystery}
  50%   Secondary challenge  {creature | trap | mystery}   - not the same kind as the first
  30%   Mystery              - if not already taken as a challenge
  1     Architecture detail unique to this location
  50%   Ambiance detail unique to this location
  80%   Treasure             {hidden | trapped | discarded}
  40%   A Unique Treasure, in place of a table citation
  30%   Lore, alongside the payload rather than instead of it
  25%   A Named Creature, where the challenge is a creature
```

High weight means the location **announces itself**. The architecture line is mandatory
because that is what does the announcing: before a party knows what is in the room, the
room has to look like somewhere that matters.

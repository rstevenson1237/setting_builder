# Safe - Key

## Provides
How a settlement comes to be holding an object that opens something somewhere else. What
earns a Keys row is `patterns/setting/Keys.md`'s.

## Spec

```
KEY
  1     Object - what it physically is
  1     Opens - the location it opens, by code
  1     Feature - the feature there it opens
  1     Holder - who has it here: the holder is the obstacle
  1     Held as - what it is to them
                   {collateral | heirloom | unexamined property | a cheap ordinary thing}
  1     Knows - whether the holder knows what it is                         {yes | no}
  1     Get by - what it takes to get it
                                 {bought | borrowed | traded | stolen | inherited | earned}
  1     Keys row - a stub row in setting/Keys.md naming where it is held and what it opens
  30%   Clue - connecting object to lock
  20%   Rival - somebody else wants it, and is closer to getting it
  1     How close - where a rival was drawn: how close, so delay has a price
```

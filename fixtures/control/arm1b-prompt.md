# Control arm 1b: the conversational prompt, as actually used

A second example of the user's working baseline, supplied verbatim from a shared
conversation. It differs from `arm1-prompt.md` in three ways that matter for P0.2: no
map is supplied, no rules document is named (whether the Design Notes were attached is
not known; treat as not attached unless the user says otherwise), and the prompt asks
for a proposal and a feedback loop rather than a finished page. It is the iterative
workflow the user described, stated in one line.

The shape it asks for is one SAFE region and one DANGEROUS region, which is the
smallest one-shot the framework's profile also names.

---

## Prompt (verbatim)

Write a dungeon module in the style of classic first edition ad&d. Include keyed
locations of a primary adventure site and a safe location for our adventuring party to
rest and resupply. Do not tell a story. Do not focus on a prewritten narrative. Give
details for the players to interact with and enough information for the referee to
make rulings. Classic sword and sorcery feel. Start with a brief proposed idea. Pause
for feedback from the user and continue iterating until finished. Writing style should
match classic adventure modules. Output in markdown.

None supplied with the prompt.

# Truths.md

## Purpose
The rules this setting keeps that a generic instance of its genre does not.

## Context
Read first:
- `GENRE.md`, and `STYLE.md` for the register a setting-level line is written in.
- `patterns/setting/Truths.md` - **how many truths, how long each runs, what kinds there
  are, what a `Handle` must be able to do, and what disqualifies a truth.** This template
  states only the shape they sit in.
- `setting/Setting.md`, `setting/History.md`

## Instructions
Fill the block below per `patterns/setting/Truths.md`'s Spec. A `Handle`'s Location Codes
are filled at 5c, once locations exist, and read `[pending 5c]` until then.

## Template
```
Truths of [Setting Name]

- **[the truth]**
  Handle: [what a party does about it, in the specific] - [Location Code(s), or `[pending 5c]`]
```

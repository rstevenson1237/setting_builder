# Truths.md

## Purpose
Establishes 1 or more unique truths that separate this setting from a generic instance of its genre.

## Context
Read first:
- `GENRE.md`
- `patterns/setting/Truths.md`
- `setting/Setting.md`
- `setting/History.md`

## Instructions
List 3-6 unique truths that separate this content and make it unique. Truths should not directly exist as objects within the setting but can define a class of object that is unique to the setting. Thematic ideas such as politics and religious ideology are also acceptable. Do not include anything that has already been established elsewhere.

**A truth is a rule, and a rule is stated in one sentence.** If it takes a paragraph, what is
being written is the *feeling* of the rule rather than the rule. Write the sentence a referee
would say at the table when a player asks "what happens if I do that."

**Every truth carries a Handle**, and the Handle is the test: what a party can *do* about
this, in the specific, and where. It names an action and at least one Location Code. A truth
whose Handle cannot be filled is not a truth - it is a tag, and it belongs in
`setting/Setting.md`'s three tags or nowhere. Delete it rather than padding it.

Handles are written at 4d, once locations exist, and the truth is **re-tested then**: a truth
that no location cashed out is cut from the file at that point. Until 4d the Handle line
states the action only, with the location left as `[pending 4d]`.

## Template
```
Truths of [Setting Name]

- **[The truth, in one sentence - the rule, not the mood]**
  Handle: [what a party does about it, in the specific] - [Location Code(s)]
```

# Truths.md

## Purpose
Establishes 1 or more unique truths that separate this setting from a generic instance of its genre.

## Context
Consult when drafting:
- `GENRE.md` - a truth should sharpen the genre's stated constraints (low magic, points of light, mythic underworld), not contradict or override them.
- `setting/Setting.md` - the name, tags, and outline a truth should deepen.
- `setting/History.md` - avoid restating anything an event already establishes.

## Instructions
List 1 or more unique truths that separate this content and make it unique. Truths should not directly exist as objects within the setting but can define a class of object that is unique to the setting. Thematic ideas such as politics and religious ideology are also acceptable. Do not include anything that has already been established elsewhere.

## Template
```
Truths of [Setting Name]

- [A unique truth, class of object, or thematic idea specific to this setting]
```

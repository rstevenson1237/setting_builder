# Setting.md

## Purpose
Defines the setting's name, thematic tags, and a short referee-facing outline - the foundation every other document builds on.

## Context
Consult when drafting:
- `GENRE.md` - the top-level thematic hints (era, tone, magic level, structure) this setting must fit. This is the first document, so it is the only fixed input.

## Instructions
Give the setting a name and three thematic tags, then a two or three sentence outline for the referee.

## Template
```
[Setting Name] *three, thematic, tags*

*[Setting Outline - two or three sentences outlining the setting for the referee]*
```

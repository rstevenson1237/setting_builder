# History.md

## Purpose
Records 1 or more major events that have shaped the setting, oldest to newest.

## Context
Consult when drafting:
- `GENRE.md` - check each event against genre before writing it: an event is a fact of the past, not a ticking clock aimed at the party. Apply the three tests in **What a line has to earn**: a party never reads this file, so an event reaches them only through what it left behind.
- `patterns/setting/History.md` - the count, the required spread across living memory, and the kinds of event.
- `setting/Setting.md` - the name, tags, and outline these events should support and explain.

## Instructions
List 3-7 major events that have influenced the setting, in order from oldest to newest.

**Two sentences per event, and the second one is usually cuttable.** History is the artifact
that most reliably swells: the temptation is to narrate the event, when the job is to state
it and name what it left.

**Every event carries a Left line**, and it is the only part of an event a party can ever
touch. Name the physical thing findable now - a ruin, a wall, a boundary, a name, a
grievance, a family that ended - and the Location Code that holds it. An event whose Left
line cannot be filled did not happen as far as the table is concerned; either give it a mark
or cut it.

Left lines are completed at 4d, once locations exist, and each event is **re-tested then**:
an event no location cashed out is either given a mark at a location or removed. Until 4d,
write the mark and leave the location as `[pending 4d]`.

## Template
```
History of [Setting Name]

[x] years ago - [What happened, in one or two sentences]
Left: [the physical thing findable now] - [Location Code(s)]
```

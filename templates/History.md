# History.md

## Purpose
Records 1 or more major events that have shaped the setting, oldest to newest.

## Context
Consult when drafting:
- `GENRE.md` - check each event against genre before writing it: an event is a fact of the past, not a ticking clock aimed at the party.
- `setting/Setting.md` - the name, tags, and outline these events should support and explain.

## Instructions
List 1 or more major events that have influenced the setting, in order from oldest to newest.

## Template
```
History of [Setting Name]

[x] years ago - [Major event that happened]
```

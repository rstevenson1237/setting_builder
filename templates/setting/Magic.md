# Magic.md

## Purpose
A reusable table of found magic items, as many rows as `BRIEF.md` sets, `setting/Magic.md`, for the referee to roll on
when a location's contents call for Magic.

## Context
```kdl
template scope="setting" writes="setting/Magic.md" shape="Magic"
read "setting/Procedures.md" part="the coin every value is stated in"
read "setting/Setting.md"
read "setting/History.md"
read "setting/Truths.md"
```

Do not consult location, region, or faction files - this table is setting-level and
reusable everywhere, not tied to any specific place or owner.

## Instructions
The results `BRIEF.md` sets, each following its fields in `patterns/Setting_Schema.md`, in randomised order.

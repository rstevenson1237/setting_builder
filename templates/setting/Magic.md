# Magic.md

## Purpose
A reusable d6 table of found magic items, `setting/Magic.md`, for the referee to roll on
when a location's contents call for Magic.

## Context
Read first:
- `GENRE.md`
- `BRIEF.md`
- `patterns/setting/Magic.md`
- `setting/Treasure1.md` - the coins and wt every value is stated in
- `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`

Do not consult location, region, or faction files - this table is setting-level and
reusable everywhere, not tied to any specific place or owner.

## Instructions
The results `BRIEF.md` sets, each following `patterns/setting/Magic.md`'s Spec, in randomised order.

## Template
```
Magic Table

| # | Item | Does | Lasts | Tell | Value | Wt |
|---|------|------|-------|------|-------|----|
| 1 | [item] | [does] | [LASTS] | [tell] | [value] | [wt] |
| ... | ... | ... | ... | ... | ... | ... |
| [N] | [item] | [does] | [LASTS] | [tell] | [value] | [wt] |
```

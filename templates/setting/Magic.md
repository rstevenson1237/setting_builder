# Magic.md

## Purpose
A reusable table of found magic items, as many rows as `BRIEF.md` sets, `setting/Magic.md`, for the referee to roll on
when a location's contents call for Magic.

## Context
Read first:
- `GENRE.md`, `STYLE.md` and `BRIEF.md`, as `python3 tools/validate_setting.py --brief setting` prints it
- `patterns/Common_Schema.md` and `patterns/Setting_Schema.md`
- `setting/Procedures.md` - the coin every value is stated in
- `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`

Do not consult location, region, or faction files - this table is setting-level and
reusable everywhere, not tied to any specific place or owner.

## Instructions
The results `BRIEF.md` sets, each following its fields in `patterns/Setting_Schema.md`, in randomised order.

## Template
```
Magic Table

| # | Item | Does | Lasts | Tell | Value | Wt |
|---|------|------|-------|------|-------|----|
| 1 | [item] | [does] | [LASTS] | [tell] | [value] | [wt] |
| ... | ... | ... | ... | ... | ... | ... |
| [N] | [item] | [does] | [LASTS] | [tell] | [value] | [wt] |
```

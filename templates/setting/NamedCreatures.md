# NamedCreatures.md

## Purpose
A registry of specific, named creatures that may appear in multiple locations and act on their own motivation, distinct from the reusable templates in `setting/Bestiary.md`. Created empty at step 2g; each entry is written at step 5a, from the table entries naming it.

## Context
Read first:
- Step 2g (creating the file): no context needed.
- Step 5a (writing an entry): `GENRE.md`, `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`, `setting/Bestiary.md`, `setting/Factions.md`, `patterns/setting/NamedCreatures.md`, and every table entry naming it.

## Instructions
- **2g**: create the file with only its title line.
- **5a**: write each entry a table names and this file lacks, per `patterns/setting/NamedCreatures.md`, with its Appears at the locations naming it.

## Template
```
Named Creatures of [Setting Name]

### [Creature Name]
Type: [Type]
AD: [Xd6+N]
MA: [Y]
Appears at: [Location Code(s)]
Role: [ROLE]
Motivation: [the standing goal driving this creature]
Reaches by: [how it reaches a party before it is met]
Remembers: [something specific it remembers]
Wants: [something specific it wants]
Description: [1-3 sentences, same style as a Bestiary entry]
Special: [what it can do that its Action Dice do not already say, or `none`]
```

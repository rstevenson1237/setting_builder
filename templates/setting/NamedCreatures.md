# NamedCreatures.md

## Purpose
A registry of specific, named creatures that may appear in multiple locations and act on their own motivation, distinct from the reusable templates in `setting/Bestiary.md`. Created empty at step 2g; each entry is written at step 5a, from the table entries naming it.

## Context
Read first:
- Step 2g (creating the file): no context needed.
- Step 5a (writing an entry): `GENRE.md`, `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`, `setting/Bestiary.md`, `setting/Factions.md`, `patterns/Common_Schema.md`, `patterns/Setting_Schema.md`, and every table entry naming it.

## Instructions
- **2g**: create the file with only its title line.
- **5a**: write each entry a table names and this file lacks, per `patterns/Setting_Schema.md`, with its Appears at the locations naming it.

## Template
```
Named Creatures of [Setting Name]

### [Creature Name]
Form: [NAME_FORM, of the name]
Type: [Type]
AD: [Xd6+N]
Special: [what it can do that its Action Dice do not already say, or `none`]
MA: [Y, omitted at 1]
Appears at: [Location Code(s)]
Reacts: [what it does on meeting a party]
Wants: [the standing goal driving this creature]
Knows: [what a party can get from it, if anything]
Description: [1-3 sentences, same style as a Bestiary entry]
```

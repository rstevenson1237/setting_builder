# Lore.md

## Purpose
A registry of written works discoverable within the setting - books, scrolls, tapestries, notes, correspondence, maps, and the like - that reveal purpose behind a region, connect its History and Truths, and offer adventure hooks. Created empty at step 2g; each entry is written at step 5a, from the table entries naming it.

## Context
Read first:
- Step 2g (creating the file): no context needed.
- Step 5a (writing an entry): `GENRE.md`, `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`, `patterns/setting/Lore.md`, and every table entry naming it.

## Instructions
- **2g**: create the file with only its title line.
- **5a**: write each entry a table names and this file lacks, per `patterns/setting/Lore.md`, with its Found at the locations naming it.

## Template
```
Lore of [Setting Name]

### [Title]
Form: [FORM - written, cut, woven, drawn or arranged]
Found at: [Location Code] [Location Name]
Voice: [whose voice, and how they are wrong or partial]
Does: [DOES]
Text: [the entry itself: what it reveals, how it connects to History or Truths, what hook it offers - short enough to read aloud in under a minute]
```

# Keys.md

## Purpose
A registry of physical objects that trigger something elsewhere - an actual key, a rod, a fitted gemstone, and the like. Created empty at step 2g; each entry is written at step 5a, from the table entries naming it.

## Context
Read first:
- Step 2g (creating the file): no context needed.
- Step 5a (writing an entry): `GENRE.md`, `setting/Setting.md`, `patterns/Common_Schema.md`, `patterns/Setting_Schema.md`, and every table entry naming it.

## Instructions
- **2g**: create the file with only its title line.
- **5a**: write each entry a table names and this file lacks, per `patterns/Setting_Schema.md`, with its Found at - where a Reward holds it - and its Opens - where a Lock names it.

## Template
```
Keys of [Setting Name]

| Name | Form | Found at | Opens | Feature | Apart | Connection |
|---|---|---|---|---|---|---|
| [Object Name] | [FORM] | [Location Code] | [Location Code] | [which Feature, and what it does] | [APART] | [CONNECTION] |
```

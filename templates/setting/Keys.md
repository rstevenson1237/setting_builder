# Keys.md

## Purpose
A registry of physical objects that trigger something elsewhere - an actual key, a rod, a fitted gemstone, and the like. Created empty at step 2h; each entry is written at step 4e, from the table entries naming it.

## Context
Read first:
- Step 2h (creating the file): no context needed.
- Step 4e (writing an entry): `GENRE.md`, `setting/Setting.md`, `patterns/setting/Keys.md`, and every table entry naming it.

## Instructions
- **2h**: create the file with only its title line.
- **4e**: write each entry a table names and this file lacks, per `patterns/setting/Keys.md`, with its Found at - where a Reward holds it - and its Opens - where a Lock names it.

## Template
```
Keys of [Setting Name]

| Name | Form | Found at | Opens | Feature | Apart | Connection |
|---|---|---|---|---|---|---|
| [Object Name] | [FORM] | [Location Code] | [Location Code] | [which Feature, and what it does] | [APART] | [CONNECTION] |
```

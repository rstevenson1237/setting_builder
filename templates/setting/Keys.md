# Keys.md

## Purpose
A registry of physical objects that trigger something elsewhere - an actual key, a rod, a fitted gemstone, and the like. Each entry is written from the table entries naming it.

## Context
```kdl
template scope="setting" writes="setting/Keys.md" shape="Keys"
read "setting/Setting.md"
read naming="Keys"
field "Keys.Opens" from="Lock.key"
```

## Instructions
Write each entry a table names and this file lacks, per `patterns/Setting_Schema.md`, with its
Opens the locations whose Lock names it, and its Found at where the key will lie: a trip of
its own, never behind its lock.

# History.md

## Purpose
Records the major events that have shaped the setting, oldest to newest.

## Context
Read first:
- `GENRE.md`, `STYLE.md` and `BRIEF.md`, as `python3 tools/validate_setting.py --brief setting` prints it
- `patterns/Common_Schema.md` and `patterns/Setting_Schema.md`
- `setting/Setting.md`
- the location entries and write-ups that hold each event's Left mark, once written

## Instructions
List the events `BRIEF.md` asks for, each following its fields in `patterns/Setting_Schema.md`,
oldest to newest, one record each. A later step adds an event only where it needs one to
account for something it wrote. With none asked for, the file is its header line.

An event's Codes are the locations whose Dressing names it in `left`, each showing its Left mark.

## Template
```
History of [Setting Name]

### [A short name for the event]
When: [recent, living, old or ancient] - [x years ago]
Event: [what happened, in one or two sentences]
Left: [the physical thing findable now]
Codes: [Location Code(s)]
```

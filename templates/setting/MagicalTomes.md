# MagicalTomes.md

## Purpose
A registry of books that teach magic, each with a title and a writer of its own. Created
empty at step 2h; each entry is written at step 4e, from the table entries naming it.

## Context
Read first:
- Step 2h (creating the file): no context needed.
- Step 4e (writing an entry): `GENRE.md`, `setting/Setting.md`, `setting/History.md`, `setting/Factions.md`, `setting/NamedCreatures.md`, `setting/Language.md`, `patterns/setting/MagicalTomes.md`, and every table entry naming it.

## Instructions
- **2h**: create the file with only its title line.
- **4e**: write each entry a table names and this file lacks, per `patterns/setting/MagicalTomes.md`, with its Found at the locations naming it.

## Template
```
Magical Tomes of [Setting Name]

### [Title]
Found at: [Location Code] [Location Name]
Teaches: [what a reader able to use it learns]
Reading: [READING]
Writer: [the entry that accounts for it]
```

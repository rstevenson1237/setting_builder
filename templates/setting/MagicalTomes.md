# MagicalTomes.md

## Purpose
A registry of books that teach magic, each with a title and a writer of its own. Created
empty at step 2g; each entry is written at step 5a, from the table entries naming it.

## Context
Read first:
- Step 2g (creating the file): no context needed.
- Step 5a (writing an entry): `GENRE.md`, `setting/Setting.md`, `setting/History.md`, `setting/Factions.md`, `setting/NamedCreatures.md`, `setting/Language.md`, `patterns/Setting_Schema.md`, and every table entry naming it.

## Instructions
- **2g**: create the file with only its title line.
- **5a**: write each entry a table names and this file lacks, per `patterns/Setting_Schema.md`, with its Found at the locations naming it.

## Template
```
Magical Tomes of [Setting Name]

### [Title]
Found at: [Location Code] [Location Name]
Teaches: [what a reader able to use it learns]
Reading: [READING]
Writer: [the entry that accounts for it]
```

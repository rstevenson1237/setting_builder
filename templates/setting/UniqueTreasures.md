# UniqueTreasures.md

## Purpose
A registry of powerful, one-of-a-kind artifacts and other magical or unique treasures, each with its own purpose and description, distinct from the random rolls on `setting/Treasure[I-V].md`. Each entry is written from the table entries naming it.

## Context
```kdl
template scope="setting" writes="setting/UniqueTreasures.md" shape="Unique Treasures"
read "setting/Setting.md"
read "setting/History.md"
read "setting/Truths.md"
read "setting/Factions.md"
read "setting/NamedCreatures.md"
read naming="Unique Treasures"
```

## Instructions
Write each entry a table names and this file lacks, per `patterns/Setting_Schema.md`, with its
Found at the locations naming it.

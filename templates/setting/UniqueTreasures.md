# UniqueTreasures.md

## Purpose
A registry of powerful, one-of-a-kind artifacts and other magical or unique treasures, each with its own purpose and description, distinct from the random rolls on `setting/Treasure[I-V].md`. Each entry is written from the table entries naming it.

## Context
Read first:
- `GENRE.md`, `STYLE.md` and `BRIEF.md`, as `python3 tools/validate_setting.py --brief setting` prints it
- `patterns/Common_Schema.md` and `patterns/Setting_Schema.md`
- `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`
- `setting/Factions.md`, `setting/NamedCreatures.md`
- every table entry naming it

## Instructions
Write each entry a table names and this file lacks, per `patterns/Setting_Schema.md`, with its
Found at the locations naming it.

## Template
```
Unique Treasures of [Setting Name]

### [Item Name]
Found at: [Location Code] [Location Name]
Does: [DOES]
Cost: [COST]
Origin: [ORIGIN, and the entry that accounts for it]
Description: [what it is, what it does, and what it costs, in a referee's words]
```

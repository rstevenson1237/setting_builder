# UniqueTreasures.md

## Purpose
A registry of powerful, one-of-a-kind artifacts and other magical or unique treasures, each with its own purpose and description, distinct from the random rolls on `setting/Treasure[I-V].md`. Created empty at step 2g; each entry is written at step 5a, from the table entries naming it.

## Context
Read first:
- Step 2g (creating the file): no context needed.
- Step 5a (writing an entry): `GENRE.md`, `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`, `setting/Factions.md`, `setting/NamedCreatures.md`, `patterns/setting/UniqueTreasures.md`, and every table entry naming it.

## Instructions
- **2g**: create the file with only its title line.
- **5a**: write each entry a table names and this file lacks, per `patterns/setting/UniqueTreasures.md`, with its Found at the locations naming it.

## Template
```
Unique Treasures of [Setting Name]

### [Item Name]
Found at: [Location Code] [Location Name]
Does: [DOES]
Cost: [COST]
Origin: [ORIGIN, and the entry that accounts for it]
Description: [what it is, what it does, and what it costs, in a referee's words]
```

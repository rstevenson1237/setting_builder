# Quests.md

## Purpose
The registry of errands running between locations - who wants what, where it is, and what
stands in the way. Stubbed at 4c as each end is written, filled at 4d.

## Context
Read first:
- `GENRE.md`
- `patterns/setting/Quests.md`
- At 4d: every location file the stub points to, both giver and target.

## Instructions
A Quest is **two-ended**: a giver location and a target location, both named by code. Both
ends exist as gazetteer stubs before any location file is written, so both can be named at
4c even when neither file is drafted yet.

At 4c record only the name and the two location codes. At 4d write the rest, with both
location files in view.

A quest states three things, and the third is the one that matters: who wants it and why
they will not go, what specifically and where, **and what stands in the way**. Two ends make
a delivery; the obstacle makes an adventure.

## Template
```
Quests of [Setting Name]

[Quest Name] - given at [Code].[N], resolved at [Code].[N]
- Wants: [who, and why they will not go themselves]
- Object: [what specifically, and where in the target location]
- Obstacle: [what stands in the way]
- Terms: ["stated in the giver's own words"]
```

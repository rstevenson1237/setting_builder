# Rumours.md

## Purpose
A referee-facing table of 20 rumours of varying truth, each a hook into the setting.

## Context
Read first:
- `GENRE.md`, and `STYLE.md` - a rumour is said aloud, so it is written to be repeated.
- `patterns/setting/Rumours.md` - **the T/P/F mix, what a rumour may point at, the ways to
  be partially true, and what `Settled at` records.** This template states only the shape
  they sit in.
- `setting/Setting.md`, `setting/History.md`, `setting/Truths.md`

## Instructions
Fill the table below per `patterns/setting/Rumours.md`'s Spec. Both referee-side columns are
authored at 2d: the T/P/F mark now, and `Settled at` as `[pending 5c]`, since no location
exists yet to name. It is filled at 5c against the locations actually built.

## Template
```
Rumours of [Setting Name]

| # | Rumour | T/P/F | Settled at |
|---|--------|-------|------------|
| 1 | [the rumour, as it would be repeated] | [T/P/F] | [Location Code(s); for P, which half is false] |
| 2 | [...] | [T/P/F] | [...] |
| ... | ... | ... | ... |
| 20 | [...] | [T/P/F] | [...] |
```

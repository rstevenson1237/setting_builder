# key-clues

What connects an object to its lock where the connection is not obvious.

1. a maker's mark shared with the lock
2. a material found in only one place
3. a name in the older tongue, per setting/Language.md
4. a measurement
5. a matching wear pattern
6. an inscription that names the lock and not the key
7. a tongue shared between the two, from setting/Language.md
